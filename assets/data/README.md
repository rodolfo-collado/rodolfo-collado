# Datos del mapa

`central-america.geojson` conserva las geometrías de once países de Natural Earth, a escala 1:110m, y únicamente la propiedad `name`. Se usa para muestrear las siluetas en caracteres; no es una imagen inventada de Centroamérica.

- Fuente: [Natural Earth Vector · Admin 0 Countries](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson).
- Términos: [Natural Earth · dominio público](https://www.naturalearthdata.com/about/terms-of-use/).
- Descarga: 17 de noviembre de 2026.

El mapa es decorativo, de baja resolución y con proyección equirectangular. El marcador señala Nicaragua de forma aproximada; no representa una dirección ni una ubicación en vivo.
